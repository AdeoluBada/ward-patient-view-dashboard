# User guide

1. Open the GitHub Pages link after deployment.
2. Select **Shift**, **Change type**, or **Category** to filter the synthetic data.
3. Review summary cards and four charts, which recalculate automatically.
4. Check the latest-record table for demonstration patient codes.
5. Reset each filter to **All** to restore the full dataset.

The site is view-only and does not write back to any spreadsheet or server. Visitors may download the public synthetic CSV. Not for clinical use.
