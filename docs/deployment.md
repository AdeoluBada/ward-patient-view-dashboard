# Publish on GitHub Pages

1. Download and extract the provided ZIP file.
2. Sign in to [GitHub](https://github.com/AdeoluBada) and create a **public** repository named `ward-patient-view-dashboard` (do not initialise with a README).
3. Select **Add file → Upload files** and upload all extracted repository files, retaining folder structure. Commit to `main`.
4. Open **Settings → Pages → Build and deployment**. Select **Deploy from a branch**, `main`, folder `/ (root)`, then **Save**.
5. Wait for deployment to finish, then open `https://AdeoluBada.github.io/ward-patient-view-dashboard/` in a private/incognito browser window.
6. Test filters, charts, sample CSV link and mobile layout. Verify the repository contains **no original workbook**.
7. On LinkedIn, go to **Profile → Add profile section → Recommended → Add featured → Add a link**, enter the live URL, and paste the featured description from `docs/linkedin_content.md`.

**Security:** GitHub Pages is publicly readable, but only collaborators with repository write access can change the hosted source. Public visitors can download and modify their own copies of public code/data. Never commit identifiable or confidential data. Review GitHub repository access settings before sharing.

**Current status:** These files are prepared locally. GitHub and LinkedIn publication must be performed by an authorised account holder; URLs are planned, not yet verified.
