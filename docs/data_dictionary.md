# Synthetic data dictionary

| Field | Meaning |
|---|---|
| date | Illustrative handover date (ISO YYYY-MM-DD) |
| shift | AM or PM |
| patient | Fictional DEMO identifier |
| category | Generalised illustrative observation category |
| change | Positive, Negative, or Neutral |
| role | Reporting role (Nurse or Support Worker) |

All records are randomly generated for demonstration. No source workbook rows were exported.
